# bashmemo

よく使うコマンドをテキストの「メモ」として保存しておき、必要なときに Bash の履歴へ読み込む小さなツールです。↑ キーや `Ctrl+R` で呼び出し、必要なら書き換えて、Enter で実行 — 長いコマンドを打ち直したり、昔のターミナル出力を遡って探したりする必要がなくなります。

[English version](README.md)

## 基本の流れ

1. **保存** — 忘れがちなコマンドをメモに書いておきます(1 行 1 コマンドのテキストファイル):

   ```bash
   @@ docker    # "docker" というメモをエディタで開く
   ```

2. **読み込み** — 必要になったらメモを呼び出します:

   ```console
   $ @ docker
   docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
   docker system df
   docker images --format "{{.Repository}}:{{.Tag}}\t{{.Size}}" | sort
   ```

3. **実行** — 表示された各行は、たった今自分で打ったかのように Bash の履歴に入っています。↑ を押すと 1 行目がプロンプトに現れ、もう一度 ↑ を押すと 2 行目に移ります。`Ctrl+R` での検索も使えます。必要なら編集して、Enter で実行します。

bashmemo がコマンドを勝手に実行することはありません。行うのは「表示」と「履歴への追加」だけで、何を実行するかは自分で決められます。

## 特徴

- **ただのテキスト** — メモは普通のテキストファイルです。編集も grep もバックアップも同期も自由にできます。
- **履歴に溶け込む** — 読み込んだコマンドは、自分で打ったコマンドと同じように ↑ / ↓ / `Ctrl+R` で呼び出せます。
- **前方一致検索** — `@ d` で `disk` と `docker` がヒット。候補一覧は履歴にも入るので、↑ と Enter だけで選べます。
- **表示だけモード** — `@ -v メモ名` なら履歴に何も追加せず、内容だけ確認できます。
- **依存なし** — 小さな Bash スクリプト 2 つだけ。ほかにインストールするものはありません。

## 動作環境

- **Bash** 専用です。`history -s` など Bash 固有の機能を使っているため、zsh などほかのシェルでは動きません。
- インストールに `git` を使います。
- 任意: `column` コマンドがあると、メモ一覧が複数列で表示されます(なければ 1 行 1 件で表示されます)。

## ファイル構成

| ファイル | 説明 |
| --- | --- |
| `load_memo.sh` | メモを表示し、コマンドを Bash の履歴へ追加します(`@` として使用)。 |
| `save_memo.sh` | メモファイルを `$EDITOR` で作成・編集します(`@@` として使用)。 |
| `memofiles/` | メモのデフォルト保存先。サンプルメモ(`git`, `docker`, `disk`, `net`, `memo`)が入っています。 |

## セットアップ

GitHub からこのリポジトリを取得し、`~/.bashrc`(または他の Bash 起動ファイル)に alias を追加します。

```bash
# 1. bashmemo を置く場所を作ります。
mkdir -p ~/scripts
cd ~/scripts

# 2. GitHub からリポジトリを取得します。
git clone https://github.com/yukiho72/bashmemo.git

# 3. ~/.bashrc に bashmemo の alias を追加します。
cat >> ~/.bashrc <<'EOF'

# bashmemo
alias @='source ~/scripts/bashmemo/load_memo.sh'
alias @@='source ~/scripts/bashmemo/save_memo.sh'
alias @v='source ~/scripts/bashmemo/load_memo.sh -v'
EOF

# 4. 現在のシェルに ~/.bashrc の設定を反映します。
source ~/.bashrc

# 5. 動作確認 — 同梱のサンプルメモが一覧表示されれば成功です。
@
```

SSH で取得したい場合は、`git clone` の行を次に置き換えてください。

```bash
git clone git@github.com:yukiho72/bashmemo.git
```

補足:

- スクリプトは `source` で実行する前提で、上記の alias もそうしています。普通に実行したスクリプトは子プロセスとして動くため、現在のシェルの履歴には何も追加できません(詳細は[内部の仕組み](#内部の仕組み))。
- `~/scripts/bashmemo` 以外の場所に置く場合は、alias のパスを置いた場所に合わせて変更してください。
- `@`, `@@`, `@v` はただの alias 名です。好みに合わせて変えてかまいません。

### 任意の設定

デフォルトでは、メモはクローンしたリポジトリ内の `memofiles/` に保存されます。`MEMOFILES_DIR` を設定すると自分のメモをリポジトリの外に置けるため、`git pull` の影響を受けなくなります。`@@` が使うエディタも指定できます。

```bash
# ~/.bashrc の alias の後に追記します。

# メモファイルをリポジトリの外に保存します。
MEMOFILES_DIR="$HOME/.local/share/bashmemo/memofiles"

# @@ が使うエディタ(デフォルト: vi)。
EDITOR=nano
```

保存先ディレクトリを作り、サンプルメモを使いたい場合はコピーします。

```bash
mkdir -p ~/.local/share/bashmemo/memofiles
cp ~/scripts/bashmemo/memofiles/* ~/.local/share/bashmemo/memofiles/  # 任意
source ~/.bashrc
```

## 使い方

### メモを作る・編集する: `@@ メモ名`

```bash
@@ etc
```

メモ `etc` をエディタ(`$EDITOR`、デフォルトは `vi`)で開きます。1 行 1 コマンドで書いて保存すれば完成です(ファイルは保存時に作られます)。メモ名に `/` やワイルドカードは使えず、`-` から始めることもできません。

### メモ一覧を表示する: `@`

```console
$ @
*** memo list (matches: 5) ***
disk    docker  git     memo    net
```

一覧の各メモ名は `@ メモ名` の形で履歴にも追加されます。↑ を押すと `@ disk`、もう一度押すと `@ docker` … と現れるので、読みたいメモを選んで Enter を押すだけです。メモ名を手で打つ機会はほとんどありません。

### メモを読み込む: `@ メモ名`

```console
$ @ git
git log --oneline --graph --all -20
git diff --stat HEAD~1
git stash list
git branch -a --sort=-committerdate
git log --author="$(git config user.name)" --since="1 week ago" --oneline
```

メモの内容が表示され、各行が順番どおり履歴に追加されます。↑ で 1 行目、↑ ↑ で 2 行目 … と呼び出せます。`Ctrl+R` の履歴検索も普段どおり使えます。呼び出したコマンドは、実行前に自由に編集できます。

### 前方一致で探す: `@ 先頭の文字 ...`

メモ名と完全一致しない引数は、名前の先頭部分として検索されます。

```console
$ @ d
*** memo list (matches: 2) ***
disk    docker
```

- 一致が 1 件だけなら、そのメモをそのまま読み込みます(`@ do` は `docker` を読み込みます)。
- 複数一致した場合は候補を一覧表示し、`@ メモ名` を履歴に追加します。↑ で選んで Enter してください。
- 完全一致が最優先です。`git` と `github` の両方があるとき、`@ git` は `git` だけを読み込みます。
- 検索語は複数指定できます。`@ d n` は `disk`, `docker`, `net` に一致します。
- 何も一致しない場合は `No memos yet. Use @@ to create one.` と表示されます。

### 履歴に入れずに表示する: `@ -v` / `@v`

```bash
@ -v git   # 表示のみ。履歴には何も追加されません
@v git     # 同じ動作をする alias
```

内容をちょっと確認したいだけのとき(マウスでコピーしたいときなど)に、履歴を汚さずに済みます。

## コマンド早見表

| コマンド | 動作 |
| --- | --- |
| `@` | 全メモを一覧表示し、`@ メモ名` を履歴に追加します。 |
| `@ メモ名` | メモを表示し、各行を履歴に追加します。 |
| `@ 先頭の文字 ...` | 前方一致検索。1 件ならそのまま読み込み、複数なら候補を一覧表示します。 |
| `@ -v ...` | 上記と同じ動作を、履歴に何も追加せずに行います。 |
| `@v ...` | `@ -v ...` の alias。 |
| `@@ メモ名` | メモを `$EDITOR` で作成・編集します。 |

## メモの書き方

1 行に 1 コマンドを、そのまま書きます。

```text
df -h --total
du -sh * | sort -rh | head -20
free -h
```

- 空行は読み込み時に無視されます。
- Windows の改行コード(CRLF)は自動で処理されます。
- 各行は書いたとおりに履歴へ入るだけで、bashmemo が実行することはありません。`#` で始まる行は実行しても何も起きないので、メモ内の見出しとしても使えます。

## サンプルメモ

すぐに試せるように、いくつかのサンプルを同梱しています。

| メモ | 内容 |
| --- | --- |
| `git` | コミットグラフ、差分の統計、stash 一覧、最近のブランチ、直近 1 週間の自分のコミット。 |
| `docker` | コンテナの状態、ディスク使用量、イメージのサイズ一覧。 |
| `disk` | ディスク・メモリの使用量、ブロックデバイス一覧。 |
| `net` | 待ち受けポート、インターフェースのアドレス、外部 IP、疎通確認。 |
| `memo` | bashmemo 自体の管理用コマンド(メモディレクトリへの移動、`~/.bashrc` の編集など)。 |

## 環境変数

| 変数 | デフォルト | 説明 |
| --- | --- | --- |
| `MEMOFILES_DIR` | スクリプトと同じ場所の `memofiles/` | メモファイルの保存先。存在しない場合は `@@` が自動で作成します。 |
| `EDITOR` | `vi` | `@@` が起動するエディタ。 |

スクリプトは(`source` によって)対話シェルの中で動くため、これらは `~/.bashrc` で `export` なしで設定してもかまいません。

## 内部の仕組み

`load_memo.sh` は Bash 組み込みの `history -s` を使って、コマンドを実行せずに現在のシェルの履歴へ追加します。シェルの履歴を変更できるのは、そのシェル自身だけです。普通に実行したスクリプトは子プロセスとして動くため、履歴への追加はプロセスの終了とともに消えてしまいます。alias が `source` でスクリプトを実行しているのはこのためです。また、スクリプトは実行後に自身が定義した関数を削除するので、シェルを汚しません。

## トラブルシューティング

- **`@: command not found` と言われる** — alias がまだ読み込まれていません。`source ~/.bashrc` を実行するか、新しいターミナルを開いてください。
- **メモは表示されるのに ↑ でコマンドが出てこない** — スクリプトを直接実行(`bash load_memo.sh`)した可能性があります。alias か `source` 経由で実行してください。
- **`@@` で見慣れないエディタが開いた** — それは `vi` です(`Esc` のあと `:q!` で終了できます)。`~/.bashrc` で `EDITOR=nano` など好みのエディタを設定してください。
- **メモが見当たらなくなった** — bashmemo は現在の `MEMOFILES_DIR` だけを見ます。`echo "$MEMOFILES_DIR"` で保存先を確認し、変更した場合はメモファイルを移動してください。
- **zsh でも使える?** — いいえ、bashmemo は Bash 専用です。
